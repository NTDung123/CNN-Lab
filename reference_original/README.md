# ANN kế thừa để đối chiếu

Nguồn ban đầu: [phanmanhcuongdev/identity_number](https://github.com/phanmanhcuongdev/identity_number).

Thư mục giữ ANN NumPy, mã huấn luyện liên quan và `model_infinity.npz`. Checkpoint được dùng khi đánh giá baseline; ứng dụng Flask hiện tại dùng hai CNN trong `weights/`.

Một số mã có điều chỉnh phục vụ đối chiếu. Xem [nguồn kế thừa và phạm vi giấy phép](../THIRD_PARTY_NOTICES.md). Đây không phải repository GitHub final của Nhóm 01.
